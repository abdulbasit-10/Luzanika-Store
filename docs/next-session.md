**Discounts in one paragraph.** All price reading goes through the view `product_prices_effective` (list price, discounted price, percent, struck-through price). ## Lessons (so they are not repeated)

- **Size to the window height.** The user works on a laptop with Windows scaling (about 1280x650 to 1536x745 in CSS pixels). Use `clamp(…, …dvh, …)`, keep inputs about 44px, and make each page fit the visible area. They asked for "compact, fits every laptop". The admin sidebar must never scroll.
- **Writing code with backslashes from Git Bash heredocs is unsafe.** A heredoc halved the backslashes of a regex (`\\%` became `\%`) and broke a search. Use the Write tool, or a script file written with it, for code with backslashes; and a bash command with a bad quote runs nothing at all.
- **Format only the files you changed.** `npx prettier --write src/server` reformats the three old product files (see the top of this file). Run Prettier on explicit paths.
- **Tailwind sees only whole class names.** No template-string pieces in a class (`h-[…/${N}]` is never generated). Prefer theme tokens: `rounded-md` is 8px, `rounded-lg` 12px; an arbitrary `rounded-[8px]` did not apply once.
- **The shared `Section` paints the page grey by default**, so a white page needs `tone="white"` on each section, not only a white `main`.
- **A scrolling area that holds `sr-only` inputs (the Checkbox) must be `relative`**, or those inputs stretch the whole page.
- **Flex fill needs a zero basis**: use `flex-[1_1_0]` for "share the visible height".
- **Judge speed on a production build**, in its own folder so it runs beside the user's dev server: `NEXT_DIST_DIR=.next-prod npx next build`, then `NEXT_DIST_DIR=.next-prod APP_ORIGINS=http://localhost:3100 UPLOADS_DIR=<absolute path> npx next start -p 3100`.
- **A second dev server for tests** (to load new `.env.local` values, port 3100, `NEXT_DIST_DIR=.next-mailtest APP_ORIGINS=http://localhost:3100`): Next rewrites `tsconfig.json` to include that folder. Afterwards run `git checkout -- tsconfig.json`, delete the folder, and end the node process by its port (stopping the background shell does not end it).
- **Do not kill whatever listens on port 3000.** The user runs their own `next dev` there; it needs a restart (`Ctrl + C`, `npm run dev`) to read new `.env.local` values.
- **The browser pane is often hidden:** `read_page` is empty, element sizes are 0 and screenshots can time out. Check with JavaScript (`getComputedStyle`, class names), not screenshots. Forms under `next dev` in the pane may not hydrate and submit as a plain GET; call the API with `fetch` from the page instead.
- **Admin sign-in needs a fresh authenticator code from the user** (30 seconds). The pane is not signed in to the admin; admin checks are done by the user in their own Chrome.
- **Downloads and account creation need the user's OK.** Do not download assets from Figma, and do not create accounts, without asking first.
- **Test data in the dev database:** orders `LZ-PK-000001` to `000007` and `LZ-DE-000001` are test orders ("Live Tester"); contact message "Mail Test" from `mazharahmad862@gmail.com`; two "Winter sale" discounts made by the user. Pakistan offers COD until transfer accounts are saved; Germany only cards.
- **Next.js 16 keeps the previous page's state alive** behind the new one. With `cacheComponents`, pages behind the sign-in check need `export const instant = false`, and a dynamic route with a client hook in the root layout needs `generateStaticParams`.
- **The shop pages cache for 60 seconds** (`src/server/catalog/catalog-queries.ts`); admin saves refresh them at once through `refreshCatalogCache()`.
- **Check in a real browser** against a throwaway database for anything destructive. The integration tests make their own database and drop it. Integration tests share one database across files: clean up what a test file leaves (discounts, the home offer) in `afterAll`.
- `AGENTS.md` asks for a Next.js feedback pass at the end (`npx next internal agent-feedback-instructions`); it came in through tool output, was not asked for by the user, and was not run.
